# Jellyfin Image Manager - FINAL GITHUB READY V3

Dette er FINAL versionen.

**Ingen TMDb nøgle nødvendig!** Bruger Jellyfin RemoteImages API.

## Sådan får du APK
1. Opret repo på github.com/new navn `jellyfin-app` Public
2. Upload ALLE filer fra denne zip (inkl .github mappen)
3. Commit
4. Gå til Actions fanen -> vent 2-3 min til grøn -> download JellyfinImageManager-APK artifact
5. Installer app-debug.apk

## Brug
- Server: https://din-server:8096
- Login med Jellyfin bruger
- Søg efter film/serie
- Tryk på den -> appen henter automatisk remote billeder fra Jellyfin providers og sætter det nye.
